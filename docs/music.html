作者 / Author @makevoid

为歌曲《You knew how to fork (you just chose not to)》（./path/to/audio.wav，检测 BPM）做一支 85 秒的流行朋克动漫 MV，要做成推特爆款。必须在第 0 帧就抓住人，静音也能看懂。画风：2000 年代的赛璐璐动画，手绘墨线、平涂色、半调放射线和棋盘格。配色：墨黑、报纸白、亮粉、电光蓝、明黄。角色：从没 fork 过的开发者、开兰博基尼的男友、妻子、妈妈，还有一个冲着开发者唱歌的朋克叙述者。每句歌词都配一个开发者会截图转发的视觉梗（FORK #834、#17 on Product Hunt、2 likes、"Liked by Mom"、visited 47 times、没人点的 Fork 按钮）。基于这个 harness 管线来做（在此粘贴 harness 的 Git 链接）：从整首歌切出 10 段，统一放在一个 24fps 的帧网格上；角色和关键帧用 gpt-image-2.5，片段用 H3（绿幕精灵或完整场景），所有字和 UI 都用 p5 画。 如果你手上没有视频要用的参考，就用你的网页搜索功能去网上找好笑的参考放进视频里，确保参考够多，让视频混乱、好笑、有意思，或者笑到停不下来。
